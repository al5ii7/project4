# Project II | NLP Business Case: Automated Customers

## Task Description
To develop a product review system powered by NLP models that aggregate customer feedback from different sources. The key tasks include classifying reviews, clustering product categories, and using generative AI to summarize reviews into recommendation articles. 

# Datasets:
Primary Dataset: [Amazon Product Reviews](https://www.kaggle.com/datasets/datafiniti/consumer-reviews-of-amazon-products/data)
Larger Dataset:[Amazon Reviews Dataset](https://amazon-reviews-2023.github.io)

1. **Review Classification**
Create a model using pretrained transformer-based model for classifying the textual content of reviews into three categories positive, negative, or neutral categories.

1-2 stars = Negative
3 star = Neutral
4-5 stars = Positive

Evaluate the model performance on a separate test dataset using various evaluation metrics:
Accuracy,Precision,Recall and F1-score.
Calculated confusion matrix to analyze model performance across different classes.

2. **Product Category Clustering**
Simplify the dataset by clustering product categories into 4-6 meta-categories.

3. **Review Summarization Using Generative AI**
Create a model by using Pretrained Generative Models to generates a short article for each product category. The output should include:
Top 3 products and key differences between them, Top complaints for each of those products, Worst product in the category and why it should be avoided. 

4. **Deployment**
Webpage in which some simple user interactions are possible. and all the three component that you did should be visible in the webpage.
